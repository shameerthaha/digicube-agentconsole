# DigiCube Agent Console — Design Context

## Users
Hackathon judges and government digital-transformation stakeholders watching a
2-3 minute screen recording, plus a demoing officer who clicks "Run agent" per
case. The on-screen persona is a licensing officer at a Gulf-region economic
affairs authority reviewing AI-prepared decisions.

## Brand Personality
Sovereign, precise, accountable. Trust with speed. The interface should feel
like a government instrument, not a SaaS dashboard: letterheads, reference
numbers, stamps, chains of custody. Three words: **authoritative, surgical,
cinematic-restrained**.

## Aesthetic Direction
"Sovereign console." Light theme primary: warm institutional paper
(`oklch(0.975 0.004 90)`), ink navy primary, ONE deep emerald accent
(`oklch(0.52 0.11 165)`), semantic amber for checkpoints / red for
escalations. Dark mode: deep navy ops room (`oklch(0.19 0.03 255)`), same
accent. No AI purple, no neon glows, no gradient text.

Type system:
- UI Latin: Public Sans (designed for US federal services)
- UI Arabic: Noto Kufi Arabic
- Documents/letterhead: Source Serif 4 + Amiri (naskh)
- Hashes/tool names/telemetry: JetBrains Mono

Signature moments (the demo must land these):
1. Provenance-linked extraction: click a field, the source document highlights
   the verbatim evidence span.
2. Hash-chained audit trail with one-click chain verification.
3. Physical "APPROVED" ink-stamp slam on officer approval.
4. Cross-case entity signals ("parallel filing detected").
5. Live SLA clock racing the 25-minute manual baseline.
6. Full EN/AR toggle flipping layout to RTL with Arabic UI.

Anti-goals: no card-in-card nesting, no decorative status dots, no
`border-l-4` accent stripes, no fake-precise numbers, no em-dashes anywhere,
no generic "AI gradient" hero. Motion is motivated only: state changes,
stamped feedback, timeline progression.

## Design Principles
1. The human is sovereign: nothing "sends" without an officer stamp.
2. Every claim links to evidence: fields → document spans, decisions → rules.
3. Speed must be legible: latencies, timers, baselines always visible.
4. Security cues are UI, not footnotes: scope chips, masked IDs, data banner.
5. Bilingual is first-class: Arabic is designed, not translated-on-top.
